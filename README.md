# 🧠 Is My Phone Listening?  
## Simulating Interest-Based Ad Targeting Using User Behavior Data

---

## 🧩 Project Overview

Have you ever experienced this?

You think about something—or casually mention it—and suddenly you start seeing ads for it on platforms like Instagram or Pinterest.

It feels like your phone is listening.

This project explores that phenomenon from a **data analytics perspective**. Instead of assuming surveillance, it demonstrates how **user behavior alone can be used to accurately predict interests and target ads**.

---

## 🎯 Objective

The goal of this project is to:

- Simulate how digital platforms infer user interests  
- Build a simple system that maps behavior → interests → ads  
- Explain why targeted ads often feel “too accurate”  
- Connect data analytics with real-world user perception  

---

## 🧠 Core Idea

Modern platforms do not need to listen to conversations. Instead, they rely on:

- Search activity  
- Click behavior  
- Viewing patterns  
- Repeated engagement  

These signals are used to build a **user interest profile**, which is then used for ad targeting.

---

## ⚙️ Project Workflow

### 1. Simulating User Behavior

- Created a dataset of user interactions across categories:
  - Fitness, Beauty, Tech, Fashion, Food  
- Each user performs multiple interactions (views/clicks)

---

### 2. Building Interest Profiles

- Aggregated user interactions by category  
- Identified top categories for each user  
- Assigned dominant interests based on engagement frequency  

---

### 3. Ad Recommendation System

- Mapped categories to relevant ads  
- Generated personalized ad recommendations for each user  
- Extended logic to include **top 2 interests** for more realistic targeting

## 💡 Key Insights

### 🔹 1. Perception vs Reality
Users often believe their phones are listening to them.

**Reality:**  
Ad targeting is driven by behavioral data, not conversations.

---

### 🔹 2. Behavioral Signals Are Powerful
Even a few interactions can strongly indicate user preferences.

---

### 🔹 3. Personalization Creates the Illusion
Highly relevant ads appear “too accurate,” creating the illusion of surveillance.

---

### 🔹 4. Feedback Loop Effect
- User interacts with a category  
- System shows more of it  
- User engages again  

This reinforces the system’s confidence in the user’s interests.
